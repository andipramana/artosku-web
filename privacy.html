Kebijakan Privasi Artosku

Terakhir diperbarui: 26 Juli 2026

Artosku adalah aplikasi pencatatan keuangan pribadi. Kebijakan ini menjelaskan data yang tersimpan di perangkat, data yang dikirim saat kamu memilih fitur tertentu, serta pilihan penghapusan yang tersedia.

Ringkasnya

Catatan keuangan utama dan foto struk disimpan di ruang aplikasi pada perangkatmu secara bawaan. Artosku tidak menyimpan salinan rutin catatan tersebut di server aplikasi. Beberapa fitur opsional—seperti backup Google Drive dan pencatatan AI—memerlukan pengiriman data yang dijelaskan di bawah.

Data akun dan autentikasi

Jika kamu mendaftar dengan email, sistem autentikasi kami memproses alamat email dan kata sandi untuk membuat serta mengamankan akun. Artosku tidak dapat membaca kata sandi dalam bentuk teks biasa. Jika kamu memilih Masuk dengan Google, Google dan sistem kami memproses informasi akun yang diperlukan untuk autentikasi, seperti email dan pengenal akun.

Data yang disimpan di perangkat

  • Catatan keuangan — transaksi, wallet, kategori, anggaran, aset, utang/piutang, tujuan tabungan, transaksi berulang, dan data terkait disimpan di database lokal aplikasi.
  • Foto struk — bila kamu memilih melampirkannya, foto disimpan di ruang penyimpanan aplikasi pada perangkat.
  • PIN dan biometrik — PIN asli tidak disimpan atau dikirim ke server; aplikasi menyimpan hash PIN beserta salt di penyimpanan aman perangkat. Sidik jari atau wajah diproses oleh sistem operasi; Artosku hanya menerima hasil berhasil atau gagal.

Data lokal dapat dipakai untuk pencatatan setelah sesi akun tersedia. Perlindungan tambahan terhadap perangkat yang hilang atau diakses orang lain juga bergantung pada keamanan perangkatmu.

Backup Google Drive (opsional)

Jika kamu memilih menghubungkan Google Drive dan membuat backup, Artosku meminta akses terbatas ke folder data aplikasi Artosku (appdata) di akun Google kamu — folder ini tersembunyi dan hanya bisa diakses lewat akun Google tersebut. Backup dapat memuat catatan lokal dan foto struk. Artosku tidak menambahkan enkripsi sendiri pada file backup; kerahasiaannya bergantung pada keamanan akun Google yang kamu hubungkan, jadi pastikan akun tersebut memakai kata sandi kuat dan verifikasi 2 langkah. Backup baru menggantikan file backup Artosku sebelumnya. Google Drive hanya bisa dihubungkan dengan akun Google yang sama dengan akun kamu masuk ke Artosku.

Menghapus akun Artosku tidak otomatis menghapus backup di Google Drive. Kamu perlu menghapus data aplikasi Artosku dari pengaturan Google Drive secara terpisah.

Fitur pencatatan AI (opsional)

Saat kamu secara sadar menjalankan pencatatan AI, Artosku mengirim kalimat transaksi, nominal yang terdeteksi, nama wallet, serta nama dan tipe kategori yang tersedia ke backend Artosku. Backend meneruskan informasi yang diperlukan ke penyedia layanan AI pihak ketiga untuk membuat saran transaksi. Untuk pembatasan pemakaian, pengenal akun, pengenal instalasi, jumlah penggunaan, dan waktu periode dapat diproses/disimpan. Catatan keuangan lokal tidak diunggah seluruhnya; jangan masukkan informasi yang tidak ingin kamu kirim ke layanan tersebut.

Laporan crash dan data teknis

Pada versi aplikasi non-debug, Firebase Crashlytics dapat menerima laporan crash/error, stack trace, versi aplikasi, informasi perangkat dan sistem operasi, serta konteks teknis. Artosku tidak secara sengaja menambahkan isi database transaksi sebagai atribut Crashlytics, tetapi pesan error dapat memuat informasi insidental. Data ini digunakan untuk mendiagnosis dan memperbaiki aplikasi.

Website dan closed testing

Jika kamu mengirim email melalui formulir closed testing, email tersebut dikirim ke dan disimpan di server kami untuk mengelola daftar tester Google Play. Gunakan email akun Google yang kamu pakai di Play Store. Kamu dapat meminta penghapusannya melalui contact.artosku@gmail.com. Website memuat Google Fonts; Google dapat menerima data permintaan teknis seperti alamat IP dan informasi browser saat halaman dimuat.

Penyedia layanan dan pembagian data

Artosku tidak menjual atau menyewakan data kamu dan tidak menggunakan SDK iklan atau Firebase Analytics. Data hanya dikirim kepada penyedia layanan sejauh diperlukan untuk fitur yang kamu pilih: penyedia layanan backend kami untuk autentikasi, daftar tester, dan pemrosesan AI; penyedia layanan AI pihak ketiga untuk permintaan AI; serta Google untuk Google Sign-In, Google Drive, Google Fonts, dan Firebase Crashlytics. Penyedia tersebut dapat memproses data teknis seperti alamat IP, user-agent, waktu permintaan, dan pengenal layanan menurut kebijakan mereka.

Hapus akun dan data

Lewat aplikasi, buka Lainnya → Hapus Akun lalu ikuti konfirmasi. Artosku menghapus catatan lokal dan foto struk akun aktif dari perangkat, kemudian meminta server kami menghapus akun autentikasi; tahap server memerlukan koneksi internet. Bila tahap server gagal, akun server mungkin masih ada meski data lokal telah lebih dahulu dihapus.

Penghapusan ini tidak otomatis menghapus backup Google Drive, PIN/pengaturan lokal, atau catatan penggunaan AI yang diperlukan untuk pembatasan layanan. Data lokal lain dapat dihapus melalui pengaturan aplikasi/perangkat. Jika tidak dapat membuka aplikasi, kirim permintaan dari email akun terdaftar ke contact.artosku@gmail.com; kami dapat menghapus akun layanan, tetapi tidak dapat menghapus data yang hanya ada di perangkat atau Google Drive milikmu.

Hapus sebagian data

Kamu dapat menghapus transaksi, wallet, kategori, aset, anggaran, serta foto struk dari layar terkait. Penghapusan lokal tidak mengubah backup yang sudah dibuat secara retroaktif; backup berikutnya akan menggantikan backup lama dengan keadaan data lokal terbaru.

Perubahan dan kontak

Kebijakan ini dapat diperbarui bila fitur atau pemrosesan data berubah. Pertanyaan privasi dapat dikirim ke contact.artosku@gmail.com.
